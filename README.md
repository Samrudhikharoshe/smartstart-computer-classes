# SmartStart Online Computer Classes Website

## Included files
- `index.html` — page content and enquiry form
- `style.css` — responsive styling
- `script.js` — mobile menu and WhatsApp enquiry form

## Run on your laptop
1. Download and extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.
4. Test the enquiry form. It opens WhatsApp with a draft message; it does not send automatically.

## Before publishing
1. Edit `script.js` and set `WHATSAPP_NUMBER` to your business number with country code, digits only.
2. Edit course fees, syllabus, timings and recorded-lesson wording in `index.html` so they match what you really offer.
3. Replace the sample business name “SmartStart Computer Classes” if desired.
4. Do not promise certificates, jobs, guaranteed results, or services you do not provide.
5. Avoid collecting unnecessary personal information. Get a parent/guardian's help if you are under 18 and check platform terms.

## Free hosting
- Create a GitHub account and upload these three files to a repository.
- For GitHub Pages, open repository Settings → Pages → deploy from the main branch and save.
- Alternatively, import the repository into Vercel and deploy with the free plan, subject to its current terms.
- A custom domain is not included for free on every platform.

## Important
This is a front-end starter template only. It has no backend, no database, no automatic payment processing and no student login. Do not ask users to submit card details or UPI PINs on this site. For payments, use a reputable payment provider and verify its current fees and eligibility before integrating it.
